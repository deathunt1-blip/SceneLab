# SceneLab v1.0

光学动捕相机部署与理论精度仿真工作台，当前发布版本为 **v1.0（1.0.0）**。提供 Windows x64 安装版和免安装版，附中文 PDF 使用说明。此版本对应当前已实现功能，不代表原始 PRD 全部条目的最终验收。

[下载 v1.0.0](https://github.com/deathunt1-blip/SceneLab/releases/tag/v1.0.0) · [更新记录](CHANGELOG.md) · [版本管理与发布流程](docs/VERSIONING.md)

## 分发版

发布文件位于 `release/SceneLab-v1.0/`。同事可运行安装程序，或完整解压免安装 ZIP 后双击 `SceneLab.exe`；不需要 Node.js。程序同目录有「使用说明.pdf」，应用内按 F1 打开。

安装版与免安装版都使用当前用户的 `%APPDATA%\\Camera Planner`，以兼容已有项目。免安装是无需安装，不表示数据随程序目录移动。分享项目和自定义相机库时，分别导出项目文件与参数库 JSON。发布包不包含本机用户数据。

本版未数字签名，未提供自动升级。企业设备受限时请交由 IT 审核。

## 源码启动

依赖已经安装、生产版本已经构建的本机，可双击根目录的 **启动 Camera Planner.vbs**。

从源码启动需要 Node.js 22.12+（分发版不需要）：

```powershell
npm ci
npm run desktop
```

开发模式：

```powershell
npm run dev
```

浏览器访问 `http://127.0.0.1:5173`。桌面版使用固定本地地址 `http://127.0.0.1:5178`，两者的存储相互独立；通过导出/打开项目和导入/导出参数库交换数据。程序与字体不依赖在线服务。

## 五分钟试用

1. 默认打开 12 × 10 × 5 m 演示场景：16 台相机、矩形桁架、平台、立柱和一个 Marker。
2. 打开右上角「相机参数库」，新建 ABC-400。基础模式通过分辨率与 FOV 推导内参；标定模式可直接录入内参和 Brown–Conrady 畸变。
3. 点击「阵列部署」，选择型号、数量、形状、高度与朝向。阵列生成后每台相机可独立编辑。
4. 选择相机，修改 XYZ / Yaw / Pitch / Roll，或使用三维操作手柄。右侧可以查看该相机的成像预览。
5. 添加方体、圆柱、墙、Marker 或四点刚体；也可多选至少三个 Marker 建立刚体。
6. 点击「运行分析」，切换覆盖数量与定位精度。拖动高度裁切查看不同高度，点击三维空间或问题条目查看逐相机诊断。
7. 点击「技术报告」，自动生成部署、俯视、前视、侧视、覆盖及精度截图。可独立切换报告语言，使用「打印 / 保存 PDF」在系统打印窗口保存 PDF。
8. 顶部导出项目。相机参数库另行导出 JSON / CSV 备份。

预置 **M4 · Demo 为合成演示参数，不代表任何厂商真实产品**。真实项目需录入经过确认的相机参数。示例名称 ABC-400 同样不代表真实产品规格。

## 青瞳相机数据库

已接入用户提供的《青瞳相机数据库标准数据表_V1.0.xlsx》：18 个型号、29 套光学配置、5 套 R3 帧模式。应用启动时一次性加入相机库，保留现有型号和项目快照；后续修改、删除不会被再次导入覆盖。相机库内按 CHINGMU 筛选，不同镜头与 R3 分辨率模式分别列出。

- 默认使用被动 Marker 距离；同时有主动距离的型号可在参数库切换。R3 的 ≥20 m 暂以 20 m 为保守仿真上限，原始限定符保留。U 系列使用表内水下有效 FOV 和未分类追踪距离。
- R1 为参考视频相机，不参与 Marker 求解，未知追踪距离保留为空。R3 可以参与求解，新部署时默认关闭，可在场景中启用。
- 原表缺失的图像点误差、最小像素阈值、最近距离与畸变采用可编辑的仿真假设（0.1 px、4 px、0 m 不限制、无畸变），不是厂商标定数据；厂商三维精度不会被当作像素误差。水体散射、浑浊和折射变化不在当前模型内。
- 每套配置保留完整相机、光学及对应帧模式的原始字段、空值、来源和备注，随 JSON / CSV 备份保存。源表及字段字典的无损提取位于 `src/camera/data/chingmu-v1.json`，带源文件 SHA-256。
- 新建或编辑后，点击底部固定的「保存型号」。保存状态在弹窗内显示；存储失败时保留草稿并提示导出备份。

## 已实现

- Design / Analysis / Report 工作模式、中文 / English 即时切换、窄窗口属性抽屉。
- 独立持久化相机库：新建、编辑、复制、删除自定义型号、厂商筛选、搜索、JSON / CSV 导入导出、参数校验。
- 项目与方案复制/切换、自动保存、项目导入导出；每台相机保存独立参数快照，库版本变动时可明确更新。
- Z 向上的场景：边界、直桁架、安装面、方体、旋转圆柱、墙、Marker 与刚体。
- 自由放置、内参模型替换、批量高度/角度编辑、成组移动和旋转、镜像、结构吸附与解除；圆形/圆弧/矩形/直线/网格/沿选中桁架阵列。
- 透视/正交/俯视/前视/侧视，列表与三维视图选择/多选、Ctrl+C/V 复制粘贴、Ctrl+D 创建副本、Ctrl+Z/Y 撤销重做；复制保留组内关系，输入框使用原生文本快捷键。
- Marker 和刚体内各 Marker 按毫米直径绘制三维球体，修改后即时更新；F 聚焦可查看小 Marker。仿真设置中的直径用于空间采样和分析点，新建 Marker 采用此值，已有对象可分别设置直径。
- Worker 中进行完整体素计算，进度显示、取消、可选自动重算、过期结果标记。
- 正向投影、内参视野、工作距离、解析几何遮挡、Marker 最小像素、边缘裁切、多失败原因与最小 Marker 直径。
- Coverage ≥1/2/3/4/5、Jacobian 协方差、XYZ / 3D RMS、均值/P90/P95/精度达标率、有效相机数、问题诊断。
- 实例化三维覆盖/精度热图，高度裁切、透明度、灰色无效点、点诊断与有效/失败观测射线。
- 相机二维投影预览保留易读的符号样式；点击「放大查看像素」打开原始分辨率的仿真图，可滚轮缩放、拖动平移、定位 Marker，最高 64×，8× 起显示逐像素网格。尺寸表显示投影宽高，不是经过曝光和阈值分割后的实测光斑尺寸。
- Marker 分析、刚体有效 Marker 与近共线判断。
- 中英文报告、章节开关、计算公式、配置与部署清单、同一渲染器自动截图、系统打印 PDF；「各相机二维成像视图」独立章节包含每台相机的概览图与 Marker 像素数据。

## 当前边界

- 本版本使用有版本字段的结构化本地存储，尚未换成 SQLite。清理浏览器/桌面应用数据会清除项目和参数库，请定期导出。分析结果不持久化，重新打开项目后自动计算。
- 已提供安装包与免安装包；尚未提供数字签名、自动升级器或账号同步。跨电脑使用项目和相机库导入导出进行迁移。
- 相机预览使用真实内参投影的线框场景；圆柱在预览中采用外包框。并非带光照、材质和逐像素深度遮挡的照片级图像。
- 热图最多绘制 60,000 个均匀抽样点；**统计始终使用全部有效采样点**。计算上限 1,200,000 个点。边界不能被步长整除时，以等间距单元中心覆盖整个边界，实际间距不超过输入值。
- 灰色热图单元表示零覆盖或不可定位；精度热图深蓝误差小、浅蓝误差大，上限为设定精度阈值的两倍。暂不支持任意手动色标与任意方向剖切面。
- Marker 投影直径按 PRD 针孔近似，畸变仅应用于点投影和 Jacobian；没有像素尺寸经验噪声模型。
- 暂未实现拖动期间的低分辨率自动预计算、完整矩形/笼状桁架编辑器、组级相对约束、连续 Hover 探测、场景 X-Ray/隐藏线模式与多光线 Marker 遮挡模型。
- 安装吸附是一次性位置操作，之后相机姿态独立存在；结构移动不会隐式带动相机。
- 所有误差为理论 1σ 三维位置 RMS，非现场系统精度承诺。标定残差、安装误差、反射、照明、温度、振动与刚体姿态误差未纳入。

## 技术说明

React + TypeScript + Three.js + Zustand；Electron 桌面壳；Vite；Vitest。

```text
src/camera/          独立相机 Repository、参数校验、JSON/CSV
src/project/         项目/方案/对象创建与文件验证
src/simulation/      纯数学、投影/遮挡/精度、Worker
src/renderer/        三维场景、相机姿态、交互、报告共用渲染
src/components/      参数库、属性、预览、诊断、报告
src/i18n.ts          集中维护的中英文语言资源
src/store.ts         项目状态、历史记录与本地保存
electron/            隔离的桌面宿主
```

世界坐标单位为 m，Z 向上。相机局部 +Z 向前、+X 向右、+Y 向图像下方。相机旋转参数为世界 Z 偏航、仰角、光轴滚转；其他物体为 `Rz(yaw) Ry(pitch) Rx(roll)`。协方差采用 `H = Σ JᵀJ / σpx²`，逆矩阵前检查退化与条件数；只对有效观测构建 H。

误差分位数只统计可定位点；覆盖率和 ≤0.3/0.5 mm 达标率以**全部有效采样点**为分母。障碍物内采样点排除，隐藏与参与仿真为独立开关。

## 验证

```powershell
npm test
npm run build
```

测试覆盖标准双目闭式解、像素噪声比例、共点退化、解析/差分 Jacobian 一致性、畸变、旋转盒与椭圆柱相交、最近遮挡体、Marker 阈值、边缘裁切、体素排除、刚体共线性和参数快照/导入校验。

当前 51 项测试通过。包含 20 × 20 × 15 m、32 台相机、0.5 m 间距共 48,000 点的集成计算；该场景为无障碍物的合成性能样例，不代表项目覆盖率或真实设备性能。

`examples/ABC-400.json` 和 `examples/ABC-400.csv` 可直接用于参数库导入试用。

## 构建发布包

先使用包含 ReportLab 和 Pillow 的 Python 运行 `scripts/create-release-assets.py` 生成图标和使用说明（使用本机微软雅黑字体），然后运行 `npm run package:win`。`scripts/prepare-release.cjs` 创建独立应用暂存目录，只复制构建产物和桌面宿主，避免带入源码、开发依赖和个人数据。安装包由 NSIS 生成；Electron 运行文件取自本机已安装的精确版本。

默认运行端口为 5178。发布验证可设置 `SCENELAB_USER_DATA_DIR` 为绝对测试目录，并设置 `SCENELAB_PORT` 使用独立端口；普通用户无需配置环境变量。
