# SceneLab v1.4.0 — Auto Deploy

新增独立「自动部署」：按场地、Marker、覆盖、精度、型号、数量、安装方式和层数搜索方案，使用 SceneLab 现有仿真引擎验证，最终指标来自正式采样。

- 周边桁架、顶装、混合、自由周边 / 三脚架与已有结构安装；支持中心权重、活动高度、可复现种子、进度及取消。
- 多目标推荐、最佳尝试、遮挡与成像尺寸诊断，以及最多 3 次放宽条件的实测对比。
- 独立三维相机与热图预览；创建新方案、替换或追加相机，安装结构可选，应用作为一次可撤销操作。
- 桌面版可选 Kimi 助手：自然语言先变成可检查的约束草稿，解释只整理已验证事实。每位用户自行配置密钥，由系统加密保存在本机，不随安装包、项目或报告分发。无 API 仍可完整离线规划。
- 更新 14 页中文 Windows PDF 及 macOS 手册；原有阵列部署、相机库、项目和报告包格式保持兼容。

Windows 使用 `SceneLab-1.4.0-Setup-x64.exe` 或完整解压 `SceneLab-1.4.0-Windows-x64.zip`。macOS 13+：M 系列选择 `arm64`，Intel 选择 `x64`；打开 DMG 后将 SceneLab 拖到 Applications。

Mac 使用 ad-hoc 签名，未经过 Apple 开发者签名或公证；x64 包在原生 Intel 构建机打包，并在 Apple Silicon 上通过 Rosetta 验证启动与渲染，Intel 实机 GPU 仍需现场验证。Windows 未数字签名。

搜索为参数模板和局部优化，不保证全局最优；理论结果需现场标定与实测确认。更新前建议导出项目与相机库备份。详细操作见仓库 `docs/AUTO_DEPLOY.md`。
