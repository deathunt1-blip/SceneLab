# SceneLab v1.4.1 — 相机型号选择修复（Windows）

修复自动部署切换到「指定型号」时默认勾选列表第一项 M4 Demo，导致它与用户选择的 MC1300 一同参与搜索的问题。

- 指定型号现在从空选择开始，不会自动加入其他型号。
- 勾选后点击列表下方「确认选择」，显示完整的已确认型号摘要；支持修改、清空和取消修改。
- 选择未确认或为空时禁止开始搜索及应用旧结果。
- 应用方案时检查每台相机的型号和参数快照是否匹配指定条件，防止型号不一致的方案写入场景。

操作：自动部署 → 指定型号 / 光学配置 → 勾选 MC1300 · Standard → 确认选择 → 开始搜索。

本次仅发布 Windows x64，Mac 暂缓。安装版运行 `SceneLab-1.4.1-Setup-x64.exe`；免安装版完整解压 `SceneLab-1.4.1-Windows-x64.zip`。保留 v1.4 功能和项目格式，现有方案不会自动更换相机，请按正确型号重新搜索并应用。通用使用说明仍为 v1.4 手册，型号选择操作以本更新说明为准。
