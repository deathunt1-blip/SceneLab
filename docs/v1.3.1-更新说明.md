SceneLab v1.3.1 首个 macOS 版本，保留 v1.3 的场景编辑、相机库、P3 IR 双目仿真、覆盖/精度分析和技术报告包功能。

### 下载与安装

要求 **macOS 13 Ventura 或更新版本**。

| Mac 类型 | 推荐下载 |
| --- | --- |
| Apple Silicon（M 系列） | `SceneLab-1.3.1-macOS-arm64.dmg` |
| Intel | `SceneLab-1.3.1-macOS-x64.dmg` |

打开 DMG，将 **SceneLab 拖到 Applications**，然后从“应用程序”打开。ZIP 是备用分发格式，完整解压后保留整个 `.app`。不需要 Node.js。

此包使用 **ad-hoc 签名**，未使用 Apple Developer ID 证书签名，也未经过 Apple 公证。首次被系统阻止时，确认来源后，在“系统设置 → 隐私与安全性”中选择“仍要打开”；公司管理的 Mac 可能需要 IT 处理。参考 [Apple 安装说明](https://support.apple.com/zh-cn/guide/mac-help/mh40616/mac)。

### Mac 适配

- Mac 应用、编辑与窗口菜单；复制/粘贴/撤销使用 ⌘C / ⌘V / ⌘Z，输入框和场景对象分别处理。
- 关闭窗口后可以点击 Dock 图标恢复，⌘Q 退出。
- “帮助 → 使用说明”打开内置离线中文 Mac 手册；附件也提供独立 HTML 说明。
- 与 Windows v1.3 交换项目文件、参数库 JSON 和技术报告包，原有文件格式不变。

本次仅增加 Mac 分发包，**Windows 同事继续使用 [v1.3.0](https://github.com/deathunt1-blip/SceneLab/releases/tag/v1.3.0)**。
