# SceneLab v1.4 自动部署

顶部工具栏的「自动部署」独立于原来的「阵列部署」。无需联网或 API 即可规划。

## 操作流程

1. 设置场地、Marker 直径、RMS 阈值、最低有效视点数及覆盖 / 精度达标比例。场地修改仅用于此次规划；默认创建新方案，保留原方案。
2. 自动比较当前相机库，或勾选特定型号及光学配置。数量支持固定值、范围以及自动搜索 8–64 台；范围模式最多 200 台。双目设备计 1 台、2 路观测。
3. 选择周边桁架、顶装、混合、自由周边 / 三脚架、仅已有结构或自动比较。已有结构包括启用且可见的桁架、方管与安装面；已有相机不加入候选的评价。
4. 选择层数及优化目标。活动高度和中心权重只影响搜索，正式指标仍覆盖整个计算空间，排除实体内部。
5. 点击「开始搜索」。任务在 Worker 中运行，显示型号筛选、数量搜索、局部优化、数量细化、正式精算及放宽条件试验阶段；随时可以取消。
6. 比较推荐方案，在独立三维视图查看临时相机、结构与覆盖 / 精度热图。可以旋转、缩放、切换俯视 / 前视及高度裁切。关闭预览不会改动场景。
7. 默认「创建新方案」，也可「替换当前全部相机」或「追加到当前方案」。可选择同时创建推荐结构；只创建相机时，会移除指向未创建结构的挂载引用。目标方案采用规划场地尺寸及 Marker / 精度设置。
8. 相机作为普通场景对象，可移动、旋转、复制、删除和重新分组。整个应用操作可一次撤销 / 重做。应用后重新运行分析，尤其是追加相机或省略推荐结构时。

## 搜索与结果的含义

- 使用现有投影、Marker 像素尺寸、遮挡、双目和理论精度计算。粗筛使用自适应间距，通常约 0.5–1 m，大场地可更粗；界面明确显示实际粗筛间距。
- 每种型号与安装方式先评价代表候选，保留各安装方式 / 目标的优胜者，再扩展数量、层数、高度、朝向和混合比例。自动模式数量节点为 8、12、16、20、24、28、32、40、48、64，在达标数量前一个区间细化。
- 最多 5 个决赛候选按用户正式采样间距重新计算，只用正式结果决定推荐并显示指标。正式采样超过 120 万点会提示调整，不会偷偷换用粗筛结果。
- 「覆盖优先」「精度优先」「综合平衡」「最少相机」可能选中同一候选，此时合并显示，并说明共享推荐。这里的“最少”仅指本轮搜索范围内已验证的候选，不是全局最优保证。
- 全场 ≥2 / ≥3 / ≥4 覆盖、精度达标率都是未加权比例。RMS 均值、P90 / P95 只统计可解样本；精度达标率以全部有效空间样本为分母，同时显示不可解样本数。
- 目标未全部达到会返回「最佳尝试」，优先中心 / 全场覆盖和视点冗余，再比较精度。不会把“精度很好但仅覆盖中心小块”的方案当成高质量推荐。
- 「安装不可行」表示生成的安装位置存在容量、层数、间距或实体碰撞问题。建议调整安装条件；参数模板搜索不穷举全部可能的安装位置。
- 诊断使用最多 320 个均匀抽样点，给出距离、Marker 过小、遮挡对象、几何 / 精度及高处覆盖问题。一个点可有多个问题。
- 最小 Marker 建议沿用原有成像公式：在其他观测条件可用的点上，找满足所需视点数的直径，显示受大小限制样本的 P90，并向上选择实用规格。它不是覆盖保证。
- 最佳尝试最多进行 3 次放宽条件的独立精算，例如增大 Marker、增加设备 / 层数、混合安装或更换型号。显示真实前后差值，不自动修改当前条件或应用试验。
- 搜索可复现：保留相同场景、相机库、条件、种子和 Planner 版本。仿真耗时和生成时间自然会变化。算法不是全局优化，结果需要现场标定和实测确认。

## Kimi 助手

桌面版在自动部署左侧的「Kimi 助手（可选）」中填写自己的密钥、模型名，勾选启用并保存。默认模型为 `kimi-k2.6`，可以按账户可用模型修改。浏览器开发版不持有密钥，继续使用离线规划。

点击「解析为草稿」后，发送需求文字、当前规划条件以及参与部署的型号 ID / 名称。响应只允许已定义的约束字段，未知型号、非法尺寸、相机坐标、伪造指标等都会被拒绝。检查草稿后点击「采用这些条件」，再编辑或启动搜索。

点击整理推荐说明时，只发送从正式仿真结果生成的事实句子。模型只能调整事实顺序；显示文字仍由本地生成，不能增加数字或隐去限制。解释不会改变部署结果。

密钥通过 Electron `safeStorage` 使用系统保护，加密保存在用户数据目录的 `ai-config.json`，不会进入项目、报告包、源码或发布包。网络请求由桌面主进程发往固定官方域名，网页无法读取已存密钥；支持关闭、移除及取消请求。操作系统不提供安全加密时拒绝保存。不要将整个用户数据目录发给同事，每人配置自己的密钥即可。

官方接口参考：[Chat Completions](https://platform.kimi.com/docs/api/chat)、[模型参数](https://platform.kimi.com/docs/api/models-overview)。联网助手不可用时，离线规划仍可完整使用。
