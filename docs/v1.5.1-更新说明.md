# SceneLab v1.5.1

发布日期：2026-10-15。Windows x64 安装版与免安装版。

新增可选的覆盖热图配色：

- **经典多色（蓝 → 红）**：保留现有配色，仍是默认模式。
- **单色蓝（浅蓝 → 深蓝）**：有效视点越多，蓝色越深；达到当前色阶上限后饱和。

在中间视图点击「覆盖数量」，左下方直接选择「覆盖配色」。场景仿真设置和自动部署面板也可修改。所选配色随方案保存，并同步到自动部署预览、技术报告与报告包。

切换配色即时生效，无需重新运行分析；覆盖数量、达标率和定位精度不受影响。零覆盖及未达标突出显示仍使用原来的灰色/灰蓝色。旧项目继续使用经典多色。

改变配色后，报告截图需重新生成，以保证热图、图例和元数据保持一致。报告包格式仍为 1.0，新增 `settings.coverage_palette` 字段（`spectrum` / `blue`）。

更新前导出项目和自定义相机库备份。关闭旧版后安装新版，或完整解压 ZIP 运行 SceneLab.exe。随包 v1.5 使用说明继续适用，新配色入口见本更新说明。
