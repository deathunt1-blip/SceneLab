# 公共可视区

在“覆盖数量”图层的“公共可视区”面板中，将“最少同时可见相机数”填写为整数 N，可以查看至少 N 台相机同时有效可见的区域。台数可以自由填写，输入 0 或点击“全部覆盖”恢复完整热图。输入值在本地记住，修改台数或高度裁切时无需重新运行分析；修改相机或场景后需要重新分析。

公共可视区按物理相机去重，同一双目设备的两个有效视点计为一台相机。相机有效可见仍采用现有的 Marker 尺寸、像素阈值、图像边界、工作距离和遮挡判定。原有视点覆盖和定位精度结果保持原有计数口径。

覆盖比例与达标体积使用当前高度裁切范围内的原始采样体积估算，障碍物内部采样不计入分母；高度裁切穿过采样单元时，按相交高度计算体积。用于显示的细网格会保守合并，合并后的区域只有在其中全部采样点达到阈值时才显示，因此显示面积与原始采样统计可能存在差别。

当 N 大于当前区域中可见的相机数量时，显示空区域，并给出没有达标区域的提示。点击显示的达标单元，可以检查对应采样点的相机观测。报告图片保留筛选台数，技术报告包同时保存物理相机计数口径、裁切高度和公共区统计。

## 开发验证

使用项目已有依赖与命令：

```sh
npm ci
npm test
npm run build
```

相关测试覆盖自由整数输入的归一化与持久化、双目物理相机去重、高度裁切、障碍物、空区域、保守热图合并和报告导出元数据。
