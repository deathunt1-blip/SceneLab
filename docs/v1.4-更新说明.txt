SceneLab v1.4.0 — Auto Deploy

新增独立“自动部署”：按场地、Marker、精度、覆盖、型号、数量、安装与层数约束生成候选，使用现有物理仿真引擎验证。
支持周边桁架、顶装、混合、自由周边与已有安装结构；粗筛、局部优化、数量细化后，以正式采样结果推荐。
推荐可独立预览覆盖与精度热图，默认创建新方案，也可替换或追加相机；应用为普通可编辑对象，支持一次撤销。
不达标返回最佳尝试、遮挡与像素等诊断，以及放宽条件的实测对比。
桌面版新增可选 Kimi 助手，解析自然语言为可检查的约束草稿；密钥仅由系统加密保存在本机，不随分发包共享。
Windows 与 macOS 均保留相同项目 / 报告包格式。Mac 需要 macOS 13+，M 系列与 Intel 分别下载对应安装包。

使用前建议导出项目和相机库备份。完整自动部署说明见 AUTO_DEPLOY.md；Windows PDF 第 13–14 页也介绍新功能。
规划是模板与局部搜索，不保证全局最优；理论仿真需结合现场标定和实测。
