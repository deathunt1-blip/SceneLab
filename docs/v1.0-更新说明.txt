SceneLab v1.0 / 1.0.0
发布日期：2026-09-18

首个供同事使用的 Windows x64 分发版本。

主要功能
- 相机参数库、青瞳数据库、场景与多方案、三维编辑和阵列部署。
- 覆盖与理论精度分析、体素热力图、分析点与逐相机失败原因。
- 场景树和三维视图选择，复制、粘贴、撤销、重做。
- Marker 毫米直径与三维尺寸同步，支持刚体各 Marker 独立设置。
- 相机二维成像概览及最高 64 倍像素查看。
- 中英文技术报告，独立章节呈现每台相机二维视图及像素数据。
- 本地自动保存、项目文件和参数库 JSON / CSV 导入导出。

本次发布
- 统一「SceneLab」名称、版本、程序图标与报告品牌。
- 提供安装版、免安装版和中文使用说明，应用内 F1 打开说明。
- 自带桌面运行环境，保留旧版数据存储位置。

范围说明
这是当前已实现功能的 v1.0，不表示原始 PRD 全部条目均已实现。
计算为理论位置 RMS，非厂商精度承诺；成像预览不是实拍照片。
没有账号同步、自动升级或数字签名。数据按当前 Windows 用户本地保存。
热图最多绘制 60,000 个采样点，统计使用全部有效采样点；计算上限 1,200,000 点。
青瞳参数源自提供的标准数据表；缺失字段的仿真假设可在参数库中查看和修改。
